# Архив экспериментов LLM-first

Эти файлы сохраняют воспроизводимость прежних исследований. Они не используются
приложением и не проверяют текущий подбор. Слабая стабильность моделей в этих
опытах стала причиной перехода к локальным правилам и AI-вопросам.

Текущие правила проверяются в `./mvnw verify`; полный путь со слайсером —
`tools/check-local-recommendations.py`. Исторические ответы находятся в
`docs/evaluations/2026-10-27/`.
