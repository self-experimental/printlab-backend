# Каталог материалов и проверяемые источники

Каталог расширяет базу проекта: восемь конкретных продуктов, восемь серий данных,
39 механических измерений. Это самостоятельный справочник свойств материалов.
Он хранится в `src/main/resources/catalog/materials.json` и входит в собранный JAR.
Исходные три испытания деталей в `data/experiments.json` сохранены отдельно.

`GET /api/materials` отдаёт версию схемы и каталог целиком. Сервер читает файл один раз
при старте, проверяет единицы, источники, диапазоны и условия печати. Ошибка каталога
останавливает запуск с диагностикой, вместо незаметного исчезновения записей.
Ответ содержит ETag и Cache-Control на час; условный GET возвращает 304.
Фронт объединяет одновременные запросы и хранит справочник в памяти на час.
Выбор материала, STL и изменение параметров не вызывают расчётов или обращений к сайтам производителей.

Все PDF скачаны и сверены 2026-10-24. В каждой записи сохранены URL, версия,
дата документа, страницы и SHA-256. Дата проверки не означает новую редакцию документа.
Выбраны указанные версии, а не меняющиеся значения из сторонних агрегаторов.
Например, для TPU взята плотность 1,25 г/см³ из паспорта 2025 года.

Храним диапазоны температуры сопла и стола, паспортную максимальную скорость,
обдув, плотность, HDT с указанной нагрузкой и требование закалённого сопла,
если оно явно приведено. Для механических испытаний сохраняем метод, направление,
значение, опубликованный разброс и условия изготовления образца.

Модули из ГПа переведены в МПа множителем 1000, вместе с разбросом.
`uncertainty` сохраняет опубликованное ± без утверждения, что это стандартное отклонение.
Неизвестные величины — `null`. Названия Horizontal / Vertical xz не переименованы в
XY / Z: без схемы производителя эти обозначения нельзя считать тождественными.
Рекомендации печати и параметры изготовления испытательного образца разделены.
В частности, для TPU рекомендация до 30 мм/с отличается от испытательной печати 36 мм/с.
Для ABS+ не внесён HDT при определённой нагрузке: в выбранном паспорте нагрузка не указана.

## Как пополнять базу

1. Найти первичный источник и конкретную редакцию, скачать PDF и записать SHA-256.
2. Добавить продукт с собственным `id`, маркой и семейством. Не усреднять разные бренды.
3. Указать получение образца (`PRINTED` либо `INJECTION_MOLDED`), метод, направление и условия.
4. Добавить доступные измерения; не выводить недостающие свойства из соседних материалов.
5. Проверить значения и единицы по таблицам и примечаниям первоисточника; добавить регрессионную проверку значимых различий.
6. Выполнить `./mvnw test`. После изменения каталога перезапустить сервер.

Проверка неизменности восьми источников (нужны Python 3 и curl):

```sh
python3 scripts/verify-material-sources.py
```

Скрипт не обновляет данные автоматически. Изменение PDF требует ручного сравнения
редакций. Рекомендуется сохранять использованные PDF в архиве проекта вне Git;
контрольная сумма позволяет отличать редакции даже при неизменном URL.

Внешний каталог можно передать переменной `PRINTLAB_MATERIALS_RESOURCE=file:/absolute/path/materials.json`.
Схема и проверки одинаковы для встроенного и внешнего файла. Это JSON-хранилище
текущего прототипа; PostgreSQL ещё не подключён. При переходе на SQL следует сохранить
связи продукт → источник → серия испытаний → измерение, включая историю редакций.

## Что эти данные дают алгоритму

Фронт выбирает продукт из каталога и передаёт `materialProfileId` вместе с `material`
(семейство). Бэк проверяет соответствие пары. Старые клиенты могут пока не передавать ID.
В исходных испытаниях деталей марка пластика не указана: ответ расчёта явно сообщает,
что паспорт выбранного продукта используется только как справочник.

Каталог **не расширяет автоматически область применимости текущего подбора**:
прочность стандартного образца в МПа не равна силе разрушения произвольной детали в Н.
Для новых материалов без испытаний детали возвращается `NO_EXPERIMENTS`, а не результат
из свойств другого пластика. Не добавлены вымышленные значения расхода, времени и силы.

Для произвольной геометрии реализован отдельный [режим подбора печати](print-plans.md)
через Bambu Studio для A1 mini. Он сравнивает время и расход материала и не вычисляет
прочность по паспортным значениям.

Для расчёта допустимой нагрузки произвольной детали по-прежнему нужны зоны крепления,
точки приложения силы и её направление, геометрическая расчётная модель и проверка на
физических испытаниях. Базу следует пополнять сериями печатных испытаний с известной
геометрией, настройками и разбросом; одних паспортных свойств материала недостаточно.
